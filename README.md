🏠 Home Row Mods (удерживай для модификатора)
```
Левая рука                    Правая рука
┌─────┬─────┬─────┬─────┐    ┌─────┬─────┬─────┬─────┐
│  A  │  S  │  D  │  F  │    │  J  │  K  │  L  │  ;  │
│Ctrl │ Alt │Shift│ GUI │    │ GUI │Shift│ Alt │Ctrl │
```

Примеры:
Ctrl+C → удерживай A, нажми C
Ctrl+Shift+S → удерживай A + D, нажми S
Cmd+V → удерживай F, нажми V
🔀 Переключение слоёв (нижний ряд левой руки)
Удержание	Слой	Назначение

X	Scroll	Трекбол → колесо прокрутки
C	Symbols	Все программистские символы
V	Hyper	Ctrl+Shift+Option+Cmd + буква

MO(1)	F-keys	Функциональные клавиши F1-F12

🚀 Слой Hyper (удерживай V)
Для быстрого запуска приложений через Raycast/Karabiner/BetterTouchTool.

Hyper = Ctrl + Shift + Option + Command

Примеры:
- V + T → Hyper+T (Telegram)
- V + S → Hyper+S (Slack)
- V + C → Hyper+C (VS Code)
- V + B → Hyper+B (Browser)
- V + M → Hyper+M (Mail)

Настрой хоткеи в Raycast: Hyper+буква → открыть приложение

💡 Советы
Home Row Mods — привыкание ~1-2 недели, потом не сможешь без них
Combos для скобок — очень быстро для кода: function() {} набирается мгновенно
J+K для языка — правая рука переключает, не прерывая поток набора
Snipe для IDE — идеально для точного выделения переменных и рефакторинга
