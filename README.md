# zmk-config for Charybdis 4x6

ZMK firmware configuration for Charybdis 4x6 split ergonomic keyboard with PMW3610 trackball.

**Updated for Zephyr 4.1 (December 2025)**

## 🎹 Шпаргалка Charybdis 4x6

### 🏠 Home Row Mods (удерживай для модификатора)

```
Левая рука                    Правая рука
┌─────┬─────┬─────┬─────┐    ┌─────┬─────┬─────┬─────┐
│  A  │  S  │  D  │  F  │    │  J  │  K  │  L  │  ;  │
│Ctrl │ Alt │Shift│ GUI │    │ GUI │Shift│ Alt │Ctrl │
└─────┴─────┴─────┴─────┘    └─────┴─────┴─────┴─────┘
```

**Примеры:**
- `Ctrl+C` → удерживай A, нажми C
- `Ctrl+Shift+S` → удерживай A + D, нажми S
- `Cmd+V` → удерживай F, нажми V

### 🔀 Переключение слоёв

| Удержание | Слой | Назначение |
|-----------|------|------------|
| C | Scroll | Трекбол → колесо прокрутки (÷32) |
| V | Snipe | Точный режим трекбола (÷4) |
| , | Snipe | Точный режим (правая рука) |
| X | Symbols | Все программистские символы |
| . | Symbols | Символы (правая рука) |
| B | Bluetooth | Управление BT-каналами |
| DEL | Hyper | Ctrl+Shift+Option+Cmd + буква |
| MO(1) | F-keys | Функциональные клавиши F1-F12 |

### 🔤 Combos (одновременное нажатие)

```
Верхний ряд:
  Q+W → [    W+E → ]    E+R → (    R+T → )

Домашний ряд:
  A+S → {    S+D → }

Правая рука:
  J+K → Переключение языка (Ctrl+Space)

Особые:
  TAB+Q → Переключение окон (Cmd+`)
```

### 🚀 Слой Hyper (удерживай DEL)

Для быстрого запуска приложений через Raycast/Karabiner/BetterTouchTool.

**Hyper = Ctrl + Shift + Option + Command**

Примеры:
- `DEL + T` → Hyper+T (Telegram)
- `DEL + S` → Hyper+S (Slack)
- `DEL + C` → Hyper+C (VS Code)
- `DEL + B` → Hyper+B (Browser)
- `DEL + M` → Hyper+M (Mail)

Настрой хоткеи в Raycast: Hyper+буква → открыть приложение

### 🖱️ Трекбол (PMW3610)

| Режим | Активация | Скорость | Описание |
|-------|-----------|----------|----------|
| Обычный | — | 2000 CPI | Стандартное перемещение курсора |
| Scroll | Удержание C | ÷32 | Трекбол работает как колесо прокрутки |
| Snipe | Удержание V или , | ÷4 | Точное позиционирование для выделения текста |

**Технические детали:**
- Драйвер: встроенный Zephyr 4.1 (`pixart,pmw3610`)
- Input processors: `zip_xy_scaler`, `zip_xy_to_scroll_mapper`, `zip_scroll_transform`
- Scroll: инверсия Y-оси включена

### 💡 Советы

- **Home Row Mods** — привыкание ~1-2 недели, потом не сможешь без них
- **Combos для скобок** — очень быстро для кода: `function() {}` набирается мгновенно
- **J+K для языка** — правая рука переключает, не прерывая поток набора
- **Snipe для IDE** — идеально для точного выделения переменных и рефакторинга
- **Snipe на запятой** — удобно для правой руки рядом с трекболом

## ⚙️ Техническая информация

- **Zephyr**: 4.1.0

### Структура файлов

```

├── charybdis.keymap          # Раскладка клавиш

    ├── charybdis_right.conf     # Настройки правой половины
    ├── charybdis_right.overlay  # Devicetree (трекбол, RGB, input processors)
    └── ...
```

### Миграция на Zephyr 4.1

Если обновляешь старый конфиг:

1. **Board name**: `nice_nano_v2` → `nice_nano@2.0.0`
2. **PMW3610 driver**: убери внешний модуль из `west.yml`, используй встроенный
3. **Devicetree**: 
   - `irq-gpios` → `motion-gpios`
   - Добавь `zephyr,axis-x = <INPUT_REL_X>` и `zephyr,axis-y = <INPUT_REL_Y>`
4. **Kconfig**: убери все `CONFIG_PMW3610_*`, добавь `CONFIG_INPUT_PMW3610=y`
5. **Scroll/Snipe**: используй ZMK input processors вместо драйверных настроек
